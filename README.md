# Techbrain Networks Website UI

A componentized smart manufacturing landing page built with React and Vite.

## Features

- React component structure
- Separate styling with CSS modules and global styles
- Sticky navigation with mobile toggle menu
- Hero section with futuristic industrial styling
- 20 product cards with 4K image prompt descriptions
- 4 service cards and FAQ section
- Responsive layout with grid and flexbox
- Smooth scroll and scroll-triggered fade-in animations
- Contact form with product selection dropdown

## Files

- `index.html` — Vite app entry point
- `package.json` — React and Vite dependencies
- `vite.config.js` — Vite configuration
- `src/main.jsx` — React bootstrap file
- `src/App.jsx` — main application layout
- `src/components/` — reusable UI sections
- `src/styles/global.css` — shared theme and utilities

## How to use

1. Run `npm install`
2. Run `npm run dev`
3. Open the local Vite URL to preview the site
